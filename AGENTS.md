# AGENTS.md

Guidance for AI agents (and people) working in the GroupDocs.Total for Node.js via Java examples.

## What this is

Runnable Node.js examples for `@groupdocs/groupdocs.total`.

- npm: https://www.npmjs.com/package/@groupdocs/groupdocs.total
- Docs: https://docs.groupdocs.com/total/
- `Examples/package.json` pins `@groupdocs/groupdocs.total` at 26.10.0

## Commands

From `Examples/`:

```bash
npm install
npm start
node run_all_examples.js --list
node run_all_examples.js --example ViewerRenderToHtml
```

## Requirements

- Node.js 20 LTS
- JRE 8 or later
- A license is optional. The runner reads `GROUPDOCS_LICENSE_PATH` or `GROUPDOCS_LIC_PATH`. Temporary license: https://purchase.groupdocs.com/temporary-license
